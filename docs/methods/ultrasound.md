# Ultrasound MLLMs

This page collects multimodal and large-language-model methods for **ultrasound**, including multi-organ ultrasound assistants, echocardiography agents, breast-ultrasound report generation, and ultrasound VQA/reasoning models.

## Research Themes

| Theme | Representative Work | Notes |
|---|---|---|
| General ultrasound assistants | Dolphin, EchoVLM, ReMUD-7B | Extend MLLMs from single-task ultrasound classification toward dialogue, report generation, and diagnostic reasoning across organs. |
| Echocardiography reasoning | Echo-alpha, EchoAgent, MARCUS | Combine video/image interpretation, measurements, Doppler/signal context, and tool-like reasoning for cardiac ultrasound. |
| Report generation | Ultrasound Report Generation MLLM, BUS-CoT-linked methods | Emphasize standardized ultrasound report text and bilingual or specialty-specific reporting templates. |
| Specialty-specific ultrasound | UTI-LLM, AbVLM-Q | Adapt ultrasound MLLMs to tongue imaging, obstetric measurement, and other specialized acquisition protocols. |
