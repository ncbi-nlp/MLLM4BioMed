# Contributing

Thank you for helping improve this repository.

## How to contribute

You can contribute by:

- adding a new model
- adding a new dataset
- correcting a broken link
- updating publication venue or paper status
- refining taxonomy or category placement

## Recommended format

Please preserve the table format used in each file.

Example:

| Model | Paper | Conf / Journal | Date |
|---|---|---|---|
| ModelName | Paper title | Venue | YYYY-MM-DD |

## Notes

- Prefer official project pages when available
- Use paper links from arXiv, conference proceedings, or journal pages
- Keep dates in `YYYY-MM-DD` format when possible
